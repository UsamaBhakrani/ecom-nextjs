After pulling the Repo, provide the env variables and run npm run init to:

1. Install NPM package dependencies.
2. Generate the Drizzle ORM client.
3. Push and Pull the Schema from NeonDB
4. Run the server

Environment Variables Required:
DATABASE_URL,
DB_NAME,
DB_USER,
DB_PASSWORD,
DB_PORT,
DOMAIN_URL,
GOOGLE_CLIENT_ID,
GOOGLE_CLIENT_SECRET,
GITHUB_ID,
GITHUB_SECRET,
AUTH_SECRET,
RESEND_API_KEY,
UPLOADTHING_SECRET,
UPLOADTHING_APP_ID,
ALGOLIA_ADMIN,
NEXT_PUBLIC_ALGOLIA_SEARCH,
NEXT_PUBLIC_ALGOLIA_ID,
